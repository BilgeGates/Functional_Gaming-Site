# Security Policy

## Supported Versions

Currently supported versions of PlayGuide:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in PlayGuide, please report it by:

1. **Email**: Send details to [your-email@example.com]
2. **GitHub**: Open a security advisory in the repository (if available)

**What to include:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

**Response time:**
- We aim to acknowledge reports within 48 hours
- Updates will be provided every 5-7 days
- Critical issues will be prioritized

**After reporting:**
- If accepted, we'll work on a fix and credit you in the release notes
- If declined, we'll explain why it's not considered a security issue

Thank you for helping keep PlayGuide secure!
